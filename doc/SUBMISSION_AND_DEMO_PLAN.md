## Pre-Submission Steps
1. Freeze features; run QA checklist.
2. Seed/reset demo data; make sure demo accounts exist.
3. Build APK; install on a clean device; run full flow.
4. Record video (1080p portrait screen capture, clear audio, 6–8 min).
5. Upload APK + video link; verify links open without login.

## Demo Video Script (≈7 min)
1. **0:00 Intro (20s)** — product idea; "not a donation platform".
2. **Home (40s)** — hero, estimate label, featured, how it works.
3. **Explore (45s)** — search, category, sort/filter, no-results state.
4. **Campaign detail (60s)** — story, inline images, sources, funding bar, use of funds, review/trust.
5. **Create (150s)** — manual path: 5 steps, validation, autosave, leave and resume draft, creator-set goal, preview, submit, status timeline. Show voice/AI mode with editable result.
6. **Review simulation (20s)** — status moves to Approved/Available (dev panel or seeded).
7. **Back a campaign (75s)** — amount, live reach, fee breakdown, simulated checkout, failure state then success, receipt, updated progress.
8. **Activity (25s)** — notifications and milestone.
9. **Dashboard & report (40s)** — tabs, estimated vs measured.
10. **Profile & secondary pages (15s)**; closing recap (15s).
